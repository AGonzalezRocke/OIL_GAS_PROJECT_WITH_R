La producción de petróleo y gas genera grandes volúmenes de información relacionada con pozos, 
operadores, campos y formaciones geológicas. Sin embargo, disponer de estos datos no garantiza 
que se aprovechen para comprender el comportamiento productivo de una región. 

El problema que aborda este proyecto consiste en identificar cómo variables operativas, geográficas 
y geológicas se relacionan con los volúmenes de producción. Por ello, el objetivo general es 
analizar la producción de petróleo y gas mediante técnicas estadísticas y herramientas computacionales, 
con la finalidad de reconocer tendencias, comparar grupos, determinar relaciones entre variables 
e identificar patrones de producción.
